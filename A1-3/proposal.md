# 📋 FestaPick 서비스 기획서

## 1. 서비스 개요 및 목적
- **서비스명**: FestaPick (페스타픽)
- **개요**: 날짜, 지역, 개인 관심사를 입력받아 실시간 웹 검색 정보와 AI 알고리즘을 결합하여 가볼 만한 축제 3곳을 맞춤형으로 큐레이션해주는 웹 서비스입니다.
- **목적**: 
  - 수많은 인터넷 정보 속에서 사용자 맞춤형 지역 축제 정보를 쉽고 빠르게 탐색.
  - 실시간 네이버 블로그 검색 데이터 연동을 통해 AI의 환각(Hallucination) 현상을 최소화하고 최근 축제 정보 제공.

---

## 2. 타겟 사용자
- **주말 여행객 / 나들이객**: 주말에 가볍게 방문할 지역 축제를 찾고 있는 사용자
- **데이트 / 가족 단위 방문객**: 특정 날짜 및 지역에 맞는 테마 여행 정보를 원하는 사용자
- **테마 여행 선호자**: 불꽃놀이, 먹거리, 음악 등 특정 주제의 문화 축제를 탐색하는 사용자

---

## 3. 페이지 및 레이아웃 구성
1. **상단 헤더 (Header)**:
   - 서비스 브랜드 로고(`🎉 FestaPick`) 및 네비게이션 메뉴(`홈`, `축제 추천`, `FAQ`)
2. **히어로 및 입력 섹션 (Main Section)**:
   - 서비스 소개 메세지
   - 여행 날짜 선택 (`date` input)
   - 선호 지역 선택 (`select` - 전국/수도권/강원/충청/전라/경상/제주)
   - 관심사 / 테마 입력 (`text` input)
   - `AI 추천 받기` 버튼
3. **추천 결과 섹션 (Result Section)**:
   - AI가 생성한 축제 추천 결과 출력 박스
4. **FAQ 섹션 (FAQ Section)**:
   - 실제 정보 여부 및 이용 요금 안내 등 자주 묻는 질문 2종
5. **푸터 (Footer)**:
   - 저작권 표시 및 기본 서비스 정보

---

## 4. 핵심 기능

### 4.1. 사용자 맞춤 입력 및 조회
- 여행 날짜, 선호 지역, 관심 키워드를 조합하여 백엔드로 API 요청 전송.

### 4.2. 실시간 웹 데이터 연동 (Naver Search API)
- 검색 쿼리: `{날짜} {지역} {관심사} 축제`
- 네이버 블로그 검색 결과를 상위 3건 수집하여 AI 프롬프트의 참고 데이터로 활용.

### 4.3. AI 맞춤 추천 생성 (OpenAI API)
- 네이버 수집 데이터 + 사용자 입력값을 바탕으로 `gpt-5.4-mini` 모델이 축제 3가지(이름, 추천 이유, 대략적 일정)를 추천문 형태로 작성.

---

## 5. AI 기능 입력 / 출력 / 실패 처리 기준
### 5.1. 입력 기준 (Input Specification)
- HTTP Method: POST (/api/recommend)
- Header: Content-Type: application/json
- Body:
    ```
    {
    "date": "2026-10-10",
    "location": "강원권",
    "interest": "음악, 단풍"
    }
    ```
    (기본값 처리: location 미입력 시 '전국', interest 미입력 시 '일반 여행')

### 5.2. 출력 기준 (Output Specification)
- HTTP Status: 200 OK
- Body:
    ```
    {
    "recommendation": "1. [축제 이름]\n- 추천 이유: ...\n- 일정: ...\n\n2. ..."
    }
    ```
### 5.3. 실패 및 예외 처리 기준 (Error Handling)
1. OpenAI API Key 미설정 오류:
    - 조건: OPENAI_API_KEY 환경 변수가 존재하지 않는 경우
    - 응답: HTTP 500, "recommendation": "서버 설정 오류: OpenAI API 키가 설정되지 않았습니다."

2. 네이버 API 오류 / 검색 결과 없음:
    - 조건: API 키 미설정, 네트워크 오류, 검색 결과가 없는 경우
    - 처리: AI 프롬프트에 '관련 검색 정보를 불러오지 못했습니다.' 입력 후, AI 자율 지식 기반으로 축제 추천을 지속 진행하여 서비스 차단을 방지.

3. 서버 내부 런타임 오류 (General Exception):
    - 조건: JSON 파싱 실패, 네트워크 타임아웃 등 처리 중 예외 발생 시
    - 응답: HTTP 500, "recommendation": "처리 중 오류가 발생했습니다: {오류 메시지}"
