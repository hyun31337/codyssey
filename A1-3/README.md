# 🌍 FestaPick (주간 지역 축제 AI 추천 서비스)

사용자가 선택한 날짜와 취향을 기반으로, 그 주에 열리는 전국의 알짜배기 지역 축제 정보를 AI가 추천해 주는 웹 서비스입니다.

## 🛠 기술 스택
- **Frontend:** HTML5, CSS3, JavaScript (Vanilla)
- **Backend:** Vercel Serverless Functions (Python)
- **AI Model:** OpenAI GPT-4o-mini
- **Deployment:** Vercel
