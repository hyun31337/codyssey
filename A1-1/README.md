# 💬 Prompt Manager (나만의 프롬프트 관리 프로그램)

> 흩어져 있던 생성형 AI 프롬프트를 체계적으로 관리하고, 파이썬과 Git을 활용해 버전 관리 역량을 키우기 위한 프로젝트입니다.

---

## 🚀 프로젝트 소개
메모장, 노션, 메신저에 흩어져 있던 프롬프트를 한곳에 모아 카테고리별로 분류하고, 키워드로 검색하며, 즐겨찾기로 빠르게 찾아쓸 수 있는 **콘솔 기반 파이썬 프로그램**입니다. 단순한 기능 구현을 넘어 Git 브랜치 전략과 기능 단위 커밋을 적용하여 버전 관리 프로세스를 경험할 수 있도록 설계되었습니다.

---

## ✨ 주요 기능

- **프롬프트 목록 보기**: 등록된 모든 프롬프트를 번호, 제목, 카테고리, 즐겨찾기 상태(⭐)와 함께 확인
- **프롬프트 추가**: 새로운 프롬프트의 제목, 내용, 카테고리를 입력하여 등록
- **카테고리별 조회**: 선택한 카테고리에 해당하는 프롬프트만 모아서 필터링
- **프롬프트 검색**: 키워드를 입력해 제목이나 내용에 포함된 프롬프트 검색
- **상세 보기**: 프롬프트 번호를 입력해 전체 내용과 상세 정보 확인
- **즐겨찾기 관리**: 자주 사용하는 프롬프트에 즐겨찾기를 추가하거나 해제, 즐겨찾기 목록만 모아보기

---

## 🏷️ 프롬프트 카테고리 안내
기본 데이터 및 프로그램에서 사용하는 카테고리 종류는 다음과 같습니다.
* **텍스트 생성**: 글쓰기, 요약, 번역 등 텍스트 기반 지시문
* **이미지 생성**: 미드저니,  DALL-E 등 이미지 키워드 및 프롬프트
* **영상 생성**: 숏폼, 비디오 제작을 위한 프롬프트
* **페르소나**: 특정 역할(역사 인물, 전문가 등) 부여 지시문
* **자동화**: 노코드/업무 자동화 관련 프롬프트
* **기타**: 그 외 분류에 속하지 않는 프롬프트
